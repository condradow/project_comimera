# Piranhas_Challange_2026
## TGBBZ I FA.11.1 
___
### Einführung
Das ist das offizielle Repository für das Projekt der Projektgruppe *TGBBZ I FA.11.1* für die Teilnahme an 
der [Software-Challange Germany 2026 Piranhas](https://software-challenge.de/).
___
### Gliederung
Im `ExamplePlayer`-Directory befindet sich Implementation der Spielerlogik und die `Build Files`.  
Im `TestServer`-Directory befinden sich die Serverdateien der Software Challange.
